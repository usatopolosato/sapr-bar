# САПР BAR

Приложение на PyQt6 для работы со стержневыми системами на растяжение и сжатие.
Автор: usatopolosato.

Текущий этап - интерактивный прототип интерфейса. Доступны главное меню,
создание и выбор рабочего пространства в текущем сеансе, меню модулей
и дизайн препроцессора. Процессор и постпроцессор представлены заглушками.

## Запуск

Требуются Python 3.11 или новее и PyQt6 6.6.1 или новее в пределах версии 6.
Из корня репозитория:

```powershell
python main.py
```

Для отдельного окружения:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e .
.\.venv\Scripts\python -m sapr
```

## Структура

```text
main.py
pyproject.toml
src/sapr/
    app.py
    ui/
        main_window.py
        loader.py
        project_dialog.py
        preview_data.py
        formatting.py
        theme.py
        pages/
            welcome.py
            project_hub.py
            preprocessor.py
            placeholder.py
        widgets/
            structure_view.py
    resources/
        forms/
            main_window.ui
            welcome.ui
            project_dialog.ui
            project_hub.ui
            preprocessor.ui
            placeholder.ui
        styles/
            theme.qss
```

Формы открываются в Qt Designer. Общая тема QSS подключается при запуске
приложения. Разметка хранится в UI-файлах, обработчики действий - в классах
страниц. MainWindow отвечает за навигацию через QStackedWidget.
StructureView отвечает за графическую сцену. Размеры панелей меняются
через QSplitter.

## Просмотр препроцессора

Режимы Конструкция и Нагрузки переключают изображение схемы.
Исходные данные открывают узлы, Таблицы увеличивают табличную панель.
Стержень можно выбрать на схеме или в таблице. Панель свойств следует
за выбором. Колесо мыши меняет масштаб, перетаскивание перемещает схему,
кнопка Вписать восстанавливает обзор. Сетку можно отключить.

Все физические величины демонстрационного набора хранятся как Decimal
в единицах СИ. Значения создаются из строк. Длина хранится в метрах,
площадь в квадратных метрах, модуль упругости и допускаемое напряжение
в паскалях, сосредоточенная сила в ньютонах, погонная нагрузка в ньютонах
на метр. Режим Точно показывает полную десятичную запись. Режим Кратко
округляет только отображаемую мантиссу до трёх знаков после точки.
Если результат помещается в четыре целых и три дробных разряда,
экспонента не выводится. Например, 2 и 1.234 остаются обычными числами,
а 210000000000 отображается как 2.1e11. Конечные нули опускаются.
Исходные значения Decimal не округляются. Преобразование во float
применяется только к экранным координатам для отрисовки средствами Qt.

Кнопка Тема в правом верхнем углу открывает выбор системного, светлого
или тёмного оформления. По умолчанию используется тема системы.
Системный режим отслеживает изменения оформления Windows во время работы.
Ручной выбор сохраняется между запусками через QSettings. Палитра схемы,
диалогов и таблиц меняется вместе с темой приложения.

Данные модели доступны только для чтения. Создание рабочих пространств
действует в пределах текущего запуска. Сохранение и чтение файлов проектов,
диагностика исходных данных и расчёты будут добавлены на следующих этапах.
Файл MD не используется.

Сочетания клавиш: Ctrl N - новый проект, Ctrl O - выбор проекта,
Escape - возврат к меню. Минимальный размер рабочей области окна
1100 на 760 логических пикселей.

## Оформление

Документация Python оформляется на русском языке в Google-style docstrings
с тройными одинарными кавычками. В UI и QSS комментарии не используются.
Текст интерфейса содержит буквы, цифры, пробелы и короткий дефис.
В числовых значениях допустимы десятичная точка и экспоненциальная запись.
