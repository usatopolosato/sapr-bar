САПР BAR
Автор: Usatopolosato

Приложение на PyQt6 для расчёта осевого растяжения и сжатия стержней.
Препроцессор, процессор и постпроцессор работают в едином окне.
Расчёты выполняются на Decimal. Матрица хранится тремя диагоналями,
система решается прогонкой за линейное время и с линейной памятью.

Запуск из исходников
python -m pip install -e ".[test]"
python main.py

Проверки
python -m pytest -q
python scripts/benchmark.py --output .preview/performance.json

Документация
docs/Руководство.txt - установка, работа с проектом и форматы файлов.
docs/Сборка.txt - воспроизводимая сборка EXE и установщика Windows.
docs/Обзор файлов.txt - назначение файлов и результаты рефакторинга.

Примеры находятся в папке Проекты. Для расчёта сначала нажмите Проверить.
Сохранить записывает только CN, LD и KPR. Только успешная проверка
создаёт CNX и LDX, необходимые процессору. После расчёта доступны
эпюры N, напряжений, перемещений и текстовый отчёт project.txt.
