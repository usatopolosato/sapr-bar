САПР BAR

Учебная программа для расчёта растяжения и сжатия цепочки стержней.
Написана на Python и PyQt6. Автор Usatopolosato.

Для каждого стержня задаются длина, площадь сечения, модуль упругости,
допускаемое напряжение и равномерная продольная нагрузка. В узлах можно
задать сосредоточенные силы и закрепления. Все величины вводятся в СИ.

Программа собирает систему уравнений методом перемещений и решает её
прогонкой. В процессоре можно посмотреть матрицу жёсткости, граничные
условия, прямой и обратный ход. В постпроцессоре доступны эпюры силы N,
напряжения и перемещения, значения в сечении, таблицы и проверка прочности.
Вычисления выполняются с Decimal, округление задаётся для отображения.

Запуск из исходников

Нужен Python 3.11 или новее. Команды для Windows выполняются из папки
репозитория. Они создают отдельное окружение и устанавливают зависимости.

python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[test]"
.venv\Scripts\python.exe main.py

Первый расчёт

1. Откройте project.kpr из одной из папок Проекты/Единичные или создайте
   свой проект и заполните таблицы стержней и узлов в препроцессоре.
2. Нажмите Проверить. Программа сохранит данные и укажет ошибки ввода.
3. После успешной проверки перейдите в процессор и выполните расчёт.
4. Откройте постпроцессор. Для просмотра результатов доступны вкладки
   Эпюры, График и Таблица. Кнопка Отчёт сохраняет TXT или HTML.

Колесо мыши меняет масштаб эпюр под курсором, перетаскивание с нажатой
левой или средней кнопкой перемещает вид. Ctrl + колесо меняет масштаб
по длине, Shift + колесо по высоте. Двойной щелчок возвращает полный вид.
Щелчок по эпюре выбирает сечение.

Файлы проекта

В каждой папке проекта лежат project.kpr с настройками, project.cn
с параметрами конструкции и project.ld с нагрузками и закреплениями.
После успешной проверки создаются project.cnx и project.ldx для расчёта.
Отчёт сохраняется рядом как project.txt или project.html.
Импорт и экспорт JSON доступны в меню Проект.

Сборка для Windows

Для сборки EXE нужны Python 3.11 x64 и Inno Setup 7. Команды приведены
в docs/Сборка.txt. После сборки в dist появляются переносимый EXE
и установщик SAPR-BAR-0.1.0-setup.exe.

Установщик предлагает сохранить 12 задач в единичных величинах в папку
Документы/САПР BAR/Примеры. При повторном запуске установщика можно
удалить программу. Учебные задачи сохраняются в Документах.

Проверка кода

.venv\Scripts\python.exe -m pytest -q

Тесты проверяют расчёт по эталонным задачам, чтение файлов, сохранение
проектов, интерфейс и формирование отчётов.

Исходный код расчёта находится в src/sapr/domain, работа с файлами
в src/sapr/storage, интерфейс в src/sapr/ui. Назначение каждого файла
описано в docs/Карта кода.txt. Подробная инструкция по работе с программой
и форматам данных находится в docs/Руководство.txt.
